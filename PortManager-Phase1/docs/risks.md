# 问题与风险清单

## R-001 Chrome 136 远程调试限制

- 现象：使用默认浏览器用户数据目录时，远程调试参数可能被忽略。
- 触发条件：Chrome 136 或更高版本，且使用默认数据目录。
- 影响：浏览器启动但调试接口不可访问。
- 处理：Launch 强制使用 F 盘非默认配置目录。
- 当前状态：已在实现和文档中约束。

## R-002 登录状态缺少独立鉴权证据

- 现象：CDP 可以确认浏览器与页面，但不能证明业务账号已登录。
- 触发条件：没有受控只读鉴权证据。
- 影响：无法可靠返回“已登录”。
- 处理：明确登录页可标记“未登录”，其余保持“登录状态未知”。
- 当前状态：符合本阶段安全边界；未来由 BSClaw 接入真实鉴权契约。

## R-003 活动浏览器阻止编辑和删除

- 现象：端口存在监听进程时，编辑、启停或删除被拒绝。
- 触发条件：浏览器或其他进程仍监听登记端口。
- 影响：用户需先关闭对应进程。
- 处理：输出进程名称和 PID，不自动结束用户进程。
- 当前状态：写锁内二次检查已实现；真实监听和真实租约拒绝已自动回归，用户长期运行环境仍待验收。

## R-004 CDP 端点版本差异

- 现象：不同 Chromium 版本可能改变错误响应或页面打开行为。
- 触发条件：浏览器不支持标准 `/json/version`、`/json/list` 或 `PUT /json/new`。
- 影响：连接、页面打开或回查失败。
- 处理：所有层级独立报告，不返回静态成功。
- 当前状态：依赖用户真实浏览器验证。

## R-005 远程主机安全边界

- 现象：CDP 对浏览器具有高权限。
- 触发条件：把调试端口暴露到非回环网络。
- 影响：可能扩大浏览器控制面。
- 处理：登记拒绝远程 DNS 和公网 IP，只接受明确私网/链路本地/ULA IP；远程资源只做状态读取；Open 和 CDP 写操作只允许回环地址。
- 当前状态：公网拒绝、私网登记与私网 Open 拒绝已回归。

## R-008 重定向标准输入结束时菜单循环

- 现象：首次自动启动检查中，菜单读取完标准输入后会重复显示。
- 触发条件：通过重定向标准输入运行交互菜单，且输入流已结束。
- 影响：自动验收进程不能自行退出。
- 已尝试：终止本次测试进程，增加输入裁剪和重定向输入结束时的安全退出。

## R-009 PSScriptAnalyzer 不可用

- 现象：现场未安装 PSScriptAnalyzer。
- 触发条件：尝试执行附加 PowerShell 规则检查。
- 影响：本轮没有 PSScriptAnalyzer 规则报告。
- 处理：未为此下载依赖，避免在 C 盘产生模块缓存；已使用 PowerShell 5.1 原生解析器、实际进程启动和 JSON 运行检查替代。
- 当前状态：非阻塞；真实慧策环境测试仍由用户执行。

## R-010 浏览器失败回收边界

- 现象：Chromium 可能把初始启动进程转交给多个子进程。
- 触发条件：Launch 已启动浏览器，随后 CDP、页面、超时或回查失败。
- 影响：只停止 Start-Process 返回 PID 可能留下子进程和端口。
- 处理：仅匹配本次根 PID、后代、调试端口、F 盘 profile 和创建时间，失败时强制回收；不处理连接前已存在的用户浏览器。
- 当前状态：真实 Google Chrome 失败路径回归后残留匹配进程为 0；不同 Chrome 企业策略仍需用户环境复验。

## R-011 隔离回归数据

- 现象：自动回归需要创建真实资源记录、租约和浏览器 profile。
- 触发条件：执行 `tests\run-business-regression.ps1`。
- 影响：测试会在 F 盘产生运行证据，但不应污染源码 `data` 或正常 `runtime`。
- 处理：通过进程环境变量把数据和日志固定到 `tests\runtime\business-regression-*` 唯一目录，并比较源码基线数据文件前后哈希。
- 当前状态：源码数据哈希未变；测试运行目录被 Git 忽略，可按用户确认后单独清理。

## R-012 重定向输入的 UTF-8 BOM

- 现象：Windows PowerShell 通过 `Process.StandardInput` 驱动菜单时，首行可能只包含 BOM，导致菜单把它当成无效操作。
- 触发条件：测试工具或未来调用器以带 BOM 的重定向标准输入驱动交互菜单。
- 影响：真实的菜单选择可能未被读取，首次注册被测试工具误判为失败。
- 处理：应用对重定向输入逐行读取并跳过仅含 BOM 的主菜单前导空行；回归启动器使用 F 盘隔离目录中的无 BOM 输入文件。
- 当前状态：首次注册向导针对性复测通过，完整自动回归 RG-015/RG-019 通过。
