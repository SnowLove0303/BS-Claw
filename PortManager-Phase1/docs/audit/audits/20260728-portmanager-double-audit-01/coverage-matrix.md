# 全业务流程覆盖矩阵

状态含义：已验证=有真实执行证据；部分验证=只覆盖了部分条件；未验证=没有真实执行证据；不适用=当前阶段明确不提供。

## 一、入口与通用交互

| 场景 | 覆盖要求 | 当前状态 |
|---|---|---|
| 中文菜单启动 | 菜单显示、输入 0–8、退出 0 | 已验证 |
| 菜单非法输入 | 空输入、字母、负数、9、带空格和 BOM | 部分验证 |
| 标准输入结束 | EOF 后安全退出且不写入半成品 | 已验证 |
| Text 模式 | 提示、表格、失败下一步 | 部分验证 |
| Json 模式 | stdout 只有一个 JSON、stderr 为空、失败非零退出码 | 部分验证 |
| 任意当前目录 | 运行数据仍进入 F 盘 runtime | 已验证 |
| 重启恢复 | 应用异常退出、重新启动、租约和状态恢复 | 未验证 |

## 二、注册流程

| 场景 | 覆盖要求 | 当前状态 |
|---|---|---|
| 空库首次注册 | 自动发现 Chrome、默认选择、默认名称、自动端口、F 盘 profile | 已验证 |
| 已有慧策 Chrome | 发现多个 Chrome、选择指定页面、ConnectOnly 注册 | 部分验证（真实 Chrome 页面已直接注册并识别） |
| 无慧策页面 | 默认自动启动 Chrome、打开慧策登录页 | 已验证（未登录页） |
| 高级设置 | 主机、端口、连接方式、Chrome 路径、profile、页面规则、登录规则、备注 | 部分验证 |
| 直接回车 | 资源名和所有默认配置的最简路径 | 已验证 |
| 无效端口 | 0、65536、非整数、占用端口 | 已验证 |
| 无效主机 | 非法主机、公网 IP、DNS 主机名、私网 IP | 已验证 |
| 重复注册 | 同 host/port 重复注册 | 已验证 |
| 注册并发竞态 | 检测后、保存前端口被占用 | 未验证；存在代码风险 CA-P1-001 |
| 注册后自动检查 | 状态写入、后续打开/重检/返回菜单 | 已验证 |

|---|---|---|

## 八、当前审计边界结论

当前不能以“20 项自动回归通过”概括为全流程通过。至少还需补做：已有慧策 Chrome 选择、已登录正向证据、登录失效、停用后打开、全部字段编辑、CheckAll 多资源、租约过期、应用重启恢复、页面正确激活、无页面新建、错误确认删除、注册并发竞态和回归脚本中断汇总。
