# 业务流程图

```text
空库启动
  -> 注册慧策通端口
  -> 持久化资源编号
  -> 详情/编辑/启停/删除
  -> Check 分层检测
  -> Open 打开并回查
  -> 审计、日志、状态持久化
```

首轮运行在“注册慧策通端口”节点中断，后续依赖资源编号的主流程未能自然进入；未使用虚构资源绕过该中断。

## 优化复验流程

```text
F 盘唯一隔离运行目录
  -> 空库
  -> 真实未监听端口注册
  -> List/Detail 持久化
  -> Edit JSON
  -> Check 不可连接并保存
  -> Open 失败并保存/释放租约
  -> 并发租约占用
       -> List/Detail 显示租约
       -> Edit/Delete/Open 拒绝
  -> 真实 Google Chrome Launch
       -> 真实 CDP 启动
       -> 非慧策页面规则导致失败
       -> 回收本次浏览器进程
       -> 保存失败状态
       -> 释放租约
```

该流程使用真实端口、真实监听和真实浏览器进程；没有把非慧策页面当成慧策成功结果。

## 首次用户注册优化流程

```text
菜单 1
  -> 查找已打开且含慧策页面的 Chrome
     -> 找到：默认使用已打开的慧策通
     -> 未找到：默认自动启动新的 Chrome
          -> 自动寻找 chrome.exe
          -> 自动分配未占用端口
          -> 自动创建 F 盘 runtime profile
  -> 资源名称可直接回车
  -> 使用慧策适配器默认页面与识别规则
  -> 注册并持久化到项目 runtime
  -> 自动 Check
  -> 立即打开 / 再次检查 / 返回菜单
```

该流程的开发自动化已通过；真实慧策成功打开和登录仍等待用户现场复测。
