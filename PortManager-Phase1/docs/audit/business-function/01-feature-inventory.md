# 实际功能清单

当前入口包括：注册（Register）、列表（List）、详情（Detail）、编辑（Edit）、删除（Delete）、启用（Enable）、停用（Disable）、单端口检测（Check）、全量检测（CheckAll）、指定端口打开（Open）及中文菜单入口。

首轮自动化覆盖：空库列表、注册正常输入、无效端口、无效主机、详情不存在、全量检测空库、中文菜单退出及菜单查看列表。首轮注册正常输入失败后，依赖资源编号的详情/编辑/删除/检测/打开正向链路无法继续。

## 优化后自动化覆盖

优化回归已继续覆盖：

- 空库及真实未监听本机端口注册。
- 无效端口、无效主机、重复注册和真实监听端口冲突。
- Detail/List 跨进程持久化。
- Edit/Delete 成功与失败的纯 JSON 标准输出。
- Check 不可连接状态写入及 Open 失败状态写入。
- ConnectOnly 公网拒绝、私网登记和远程 Open 拒绝。
- 活动租约期间 List/Detail 占用展示及 Edit/Delete/Open 并发拒绝。
- 真实 Google Chrome 启动后页面失败的进程与租约回收。
