# 第一阶段真实验证记录

## 记录规则

每项只能填写真实执行结果。未使用真实端口、真实浏览器或真实慧策页面执行时，状态必须保持“待用户真实测试”。

## 用户首次复测步骤

```powershell
Set-Location 'F:\XIANGMU\BS Claw\PortManager-Phase1'
Set-ExecutionPolicy -Scope Process Bypass
.\port-manager.ps1
```

1. 菜单输入 `1`。
2. 若程序发现已经打开的慧策通 Chrome，直接回车使用它；未发现时直接回车采用“自动启动新的 Chrome”。
3. 资源名称直接回车，确认程序生成 `慧策通端口-端口号`。
4. 查看自动检查的连接、浏览器、页面和登录状态；未登录证据不足时必须是“登录状态未知”。
5. 输入 `1` 立即打开慧策通，或输入 `0` 返回菜单后再选择菜单 7。
6. 把实际资源编号、输出和结果填入下表。不要粘贴 Cookie、Token、密码或授权头。

正常运行数据固定在 `F:\XIANGMU\BS Claw\PortManager-Phase1\data\port-manager.sqlite3`；`ports.json` 仅用于首次迁移、备份或人工导出。
