# BS Claw 用户人工测试

## 测试目标

只通过 `bsclaw` 和中文菜单，确认本地服务、端口资源、慧策登录状态、任务中心和后台检测可用。普通用户不需要输入模块编号、任务编号、JSON 或内部命令。

本阶段不执行选品、分销、订单等业务写入；不删除资源、不清缓存、不自动替用户输入密码。

## 前置条件

在新 PowerShell 输入 `bsclaw`。如果无法进入中文菜单，关闭窗口后重新打开；仍无法进入时，请让管理员检查本地安装入口和 F 盘运行环境。反馈时只提供菜单上的中文提示和截图，不提供密码、Cookie、Token 或完整授权头。

## 1. 进入与退出

1. 输入 `bsclaw`。
2. 应看到“本地服务”“执行模块”“任务与审计”“资源维护”分区。
3. 输入 `0` 退出。

通过标准：菜单可读、没有要求用户填写内部编号或 JSON。

## 2. 查看本地服务总览

1. 主菜单输入 `1`。
2. 查看端口管理、慧策资源、服务插件和业务模块状态。
3. 若资源需要登录或检查，页面必须给出中文下一步。
4. 返回主菜单。

## 3. 查看端口资源与详情

1. 主菜单输入 `2`。
2. 选择一个资源。
3. 查看端口、连接状态、登录状态、最近检查时间和下一步。
4. 选择“重新检查状态”，等待结果返回。
5. 确认刚才选择的资源名称、端口和状态仍保持不变；整个过程不需要复制内部编号。

失败标准：资源选择后丢失名称或端口、未检查却显示已登录、要求用户复制资源编号或任务编号继续。

资源选择规则：单资源操作（详情、检查、打开、登录、维护）从列表输入序号；批量检查直接选择“全部启用资源”。如果未来接入明确支持多选的功能，才会提供按序号多选、全选、取消和返回；当前没有声明的多选功能不会出现在菜单中。

## 4. 查看慧策登录状态

1. 主菜单输入 `3`。
2. 查看“可继续、需登录、未验证、需修复”等状态。
3. 对需登录资源，按页面提示进入正式登录流程。

正式登录时，系统会自动弹出独立“人工处理”窗口，用户在窗口中输入企业账号、用户账号和密码（密码不回显）并确认协议。不得在 Chrome 页面手工输入或点击替代程序流程。通过标准是进入 ERP、状态显示已登录/API ready；验证码或外部风控出现时，窗口会保持等待并提供继续/取消。

如果出现验证码、短信、滑块或外部风控，当前资源会进入“等待外部验证”状态。用户只需在同一资源页面完成验证，然后在当前提示输入“继续”；输入“取消”会结束等待并释放本次登录占用。系统随后自动重新检查页面、API 和资源状态，不要求重新复制资源编号或重新拼接命令。

当页面出现验证码、短信、滑块或外部风控时，主菜单会显示“待处理人工事项”。进入菜单 `12`，选择对应资源后进入正式输入/授权入口；完成后选择“继续”，系统自动续接原任务并回查页面、接口和资源状态。选择“取消”会释放本次等待，不要求重新启动程序或复制内部编号。

## 5. 诊断、模块与任务中心

- 菜单 `4`：查看系统和资源级诊断，未验证项目必须明确显示。
- 菜单 `6`：查看已接入服务；没有真实业务模块时不得出现可执行业务入口。
- 菜单 `7`：查看最近任务。任务中心显示名称、状态、时间、进度、结果摘要和下一步，不要求复制任务编号。
- 菜单 `12`：查看待处理人工事项。这里直接列出任务名称、资源名称/端口和等待原因，并提供“进入正式输入/授权并自动继续”“取消等待”“返回”入口。
- 菜单 `8`：查看最近检查记录。
- 菜单 `9`：生成脱敏审计摘要。

## 6. 后台资源检测

1. 主菜单输入 `11`。
2. 选择“启动或恢复后台检测”。
3. 10 秒内应显示“首轮检查中/运行中”或明确失败原因。
4. 首轮完成后应显示心跳、最近一轮时间、资源总数和成功/失败数量。
5. 可选择刷新状态；异常终止时应显示“未运行或已过期”，不能继续显示实时运行。
6. 选择停止并输入明确确认，状态应为“已停止”。

后台检测不关闭 Chrome、不删除 Profile、不清理数据库。监控与人工检查可以同时进行，系统会按资源协调检查。

## 通过与失败标准

通过：用户只需 `bsclaw` 和菜单选择即可查看、检查和回查结果；状态来源和时间清楚；失败有中文原因和下一步；没有敏感信息泄露；原端口管理入口仍可进入。

失败：要求用户手写内部动作、复制任务编号、阅读原始 JSON；把未验证显示为可用；未确认就打开浏览器或登录；后台进程死亡后仍显示运行中。

## 反馈方式

反馈菜单编号、操作时间、页面中文提示和脱敏截图即可。不要提供账号、密码、Cookie、Token、完整授权头、CredentialRef 实值或 Profile 内部文件。

开发/审计命令、JSON 契约、任务编号和性能计时请参阅独立技术附录，不属于普通用户主路径。
