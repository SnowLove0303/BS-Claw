# 选品业务链与状态路径

## 主干关系

```text
用户业务目标
  -> 统一调度层识别能力
  -> 选品模块能力匹配
  -> PortManager 资源检索与预热
  -> 登录态/API-ready/权限/并发门禁
  -> 自动固化任务上下文
  -> 候选获取
  -> 条件筛选与排序
  -> 自动执行选品动作
  -> 精确结果回查
  -> 审计记录/租约释放/结果返回
```

## 服务层与业务层

- 统一调度层：负责任务生命周期、模块发现、资源匹配、前置条件、执行顺序、取消、超时、重试、恢复和结果回查编排。
- PortManager：唯一资源事实源，负责端口、Chrome/Profile、租约、资源状态和资源级能力；不承载选品业务。
- HuiceLoginAgent：负责慧策登录检测/登录协议边界；不负责选品决策。
- 选品模块：负责候选数据、筛选条件、选品动作和业务结果解释；不直接读 PortManager SQLite，不自行维护端口/Profile/租约/统一任务状态。
- HTTP connector：只封装慧策 HTTP API 调用、请求契约、脱敏和响应归一化；不取代调度层。

## 全自动阶段的分支

### A. 已有可复用登录资源

自动选择符合条件的资源 -> 申请租约 -> 预检通过 -> 执行选品 -> 回查 -> 释放租约。

### B. 无可复用登录资源

自动停止任务 -> 返回需要登录/授权的可理解原因 -> 保留可恢复任务上下文。此阶段不设计业务确认；也不得自动猜测账号、读取明文凭据或绕过安全门禁。

### C. 预检失败

自动停止 -> 记录失败门禁与事实源时间 -> 释放已申请资源 -> 返回恢复建议。不能继续调用写入 API。

### D. 外部写入后回查失败

进入结果不确定状态，不盲目重试、不重复写入；先查询任务/业务对象状态，生成可审计的待恢复结果。

## 状态最小集合

`RECEIVED -> CAPABILITY_MATCHED -> RESOURCE_BOUND -> PREFLIGHT_PASSED -> CONTEXT_SNAPSHOTED -> CANDIDATES_READY -> EXECUTING -> VERIFYING -> SUCCEEDED`

异常分支统一进入：`BLOCKED | FAILED | CANCELED | TIMED_OUT | RECOVERY_REQUIRED`，并最终执行租约和运行状态收口。
