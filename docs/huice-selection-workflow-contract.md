# 慧策 HTTP 选品工作流接入契约

本文件只定义底座预留接口，不代表慧策选品业务模块已接入。

用户路径：进入已注册模块 → 按名称/端口/状态/时间选择资源 → 刷新登录/API 状态 → 选择已注册来源路径 → 输入筛选条件和数量 → 生成只读候选计划 → 查看 dry-run → 明确确认高风险写入 → 幂等执行 → 写后回查 → 查看成功、失败、跳过、部分成功和人工事项。

业务模块必须通过统一调度器获得 `HuiceExecutionContext`，并声明 `resourceSelectionMode`、`resourceExecutionPolicy`、登录门禁、输入、确认、写入级别、超时、取消、恢复、结果视图和 `resultCheck`。当前没有真实 manifest、入口和 HTTP 连接器，不创建假按钮、不注册空模块、不返回固定业务结果。
