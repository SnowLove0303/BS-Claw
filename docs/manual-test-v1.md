# BS Claw 正式用户路径人工测试 V1.0

本文只描述普通用户可见路径。用户不需要输入 ResourceId、taskId、moduleId、action、JSON 或技术命令。

## 一、启动与预热

1. 从 BS Claw 正式入口启动。
2. 等待系统显示端口服务、慧策资源和业务模块状态。
3. 确认页面区分服务活跃、最近检查有效和资源当前可用；过期或未知状态必须显示原因和下一步。

## 二、资源列表与单资源检查

1. 进入“端口资源”。
2. 从资源名称、端口、连接、页面、登录、API、占用和更新时间中选择资源。
3. 进入资源详情，选择“重新检查状态”。
4. 等待进度结束，确认列表、详情、任务中心显示相同的状态、检查时间、来源、新鲜度和下一步。
5. 连接成功、页面正确或浏览器打开，不得单独显示为已登录；只有真实登录和 API 就绪证据同时存在时才显示已登录。

## 三、已登录资源复用

1. 选择状态为已登录且 API 已就绪的资源。
2. 选择打开或执行只读检查。
3. 系统自动复用现有资源，不弹登录窗口。
4. 用户看到阶段、进度、结果、占用释放和下一步。

## 四、新账号登录与外部验证

1. 选择明确显示需要登录的资源。
2. 选择“进入正式登录”。
3. 在独立安全窗口中输入本人账号信息并确认协议；密码不回显。
4. 如页面要求验证码或外部风控，在同一资源等待窗口完成验证后选择继续。
5. 系统自动继续原任务，并回查页面状态、API 状态、PortManager 状态、任务结果和租约。
6. 用户可选择取消、关闭窗口或等待超时；系统必须显示可理解原因，清理等待状态并释放占用。

## 五、CheckAll 与多资源策略

1. 进入“资源维护”，选择“检查全部资源”。
2. 查看总数、完成数、失败数、当前资源和逐项结果。
3. 确认结果分别显示可用、需登录、需修复、连接不可用和未知。
4. 未声明跨资源并行策略的动作不得自动并行；同一资源被占用时应显示等待、阻断或返回选项。

## 六、任务回查、取消与恢复

1. 在任务中心查看任务名称、阶段、进度、结果摘要和下一步。
2. 对可取消任务选择取消，确认任务进入取消终态。
3. 对可重试失败选择重试；业务结果未知时不得自动重试写入。
4. 关闭或重新启动入口后重新查看任务，确认失效进程、心跳、租约和锁被正确收口；不能因 PID 消失直接推断业务成功。

## 七、PortManager 维护路径

按用户菜单进入资源管理，分别人工检查注册、列表、详情、编辑、启用、停用、删除、占用、登录态检查、全量检查和打开/复用。编辑和删除必须有确认；正式资源破坏性操作只由需求与审计线程在授权隔离环境执行。

## 失败判定

出现要求用户复制内部 ID、显示 JSON 才能继续、过期快照显示为实时、浏览器打开被显示为登录成功、人工输入后原任务不续跑、租约未释放、未知结果被改写为成功/失败或业务模块显示为空壳按钮，均应记录为失败并保留当前状态、原因和回滚点。
