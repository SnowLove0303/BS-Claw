# 主干开发任务清单（规划，不代表已实现）

## P0-01 资料与契约

- 固化 module manifest、能力声明、Action/输入输出契约和版本策略。
- 声明资源选择模式、资源执行策略、登录要求、写入风险、超时/取消/恢复规则。
- 明确调度层与模块的责任边界及错误码映射。

## P0-02 独立 PowerShell 骨架

- 建立可迁移、相对路径、自发现的模块入口。
- 以 PortManager 风格拆分脚本模块，不把逻辑堆入单一主脚本。
- 提供指令化的发现、预检、执行、状态和结果查询入口。

## P0-03 调度接入

- 通过公开 adapter/service manifest 被 BSClaw-Local 自动发现。
- 资源全部由 PortManager 正式服务返回并自动绑定。
- 同资源互斥、跨资源并行策略必须由动作声明，未声明不得放行。

## P0-04 预检与上下文

- 检查资源、端口、Profile、CDP、登录态、API-ready、权限、租约和依赖。
- 固化任务输入、资源快照、规则版本、幂等键和外部上下文。
- 预检失败不得调用写入动作。

## P0-05 选品读链

- 封装候选获取、分页、限流、响应校验和数据归一化。
- 建立候选快照和条件版本；禁止固定样例和过期缓存冒充实时数据。

## P0-06 选品执行与回查

- 执行动作前自动完成规则门禁，不设置业务确认弹窗。
- 写入后通过精确业务查询/任务查询回查真实结果。
- 未知结果进入恢复，不自动重复写入。

## P0-07 状态、审计与恢复

- 状态机覆盖成功、失败、取消、超时、阻断、异常退出和恢复。
- 租约、任务和审计记录一致；日志只允许脱敏。

## P0-08 独立验证与回归

- PowerShell 语法、模块发现、契约、隔离数据库和真实只读 API 验证。
- 在授权测试资源上验证真实写入、回查、异常恢复和资源释放。
- 对 PortManager、BSClaw-Local、HuiceLoginAgent 既有路径做回归。

## P1 后续补齐

选品条件、排序与去重规则、供应商/店铺策略、商品字段映射、加入分销/发布扩展、生产 schema、性能基线和完整人工测试文档必须另行形成正式需求包后开发。
